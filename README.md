### New journey start from Today

**Today is 19th August 2025. Today I realized one big mistake that I made.**
I tried to learn everything together to become a full-stack developer.
But what really happened was that I didn’t *learn*, I only consumed tutorials and typed the same code in my VS Code.

Later I realized that the right way is to do **one thing at a time**.
So I created a new repo and started learning step by step.
That time I actually started thinking like a programmer.

Now, instead of just typing code, I:

* Add comments,
* Dry run my code,
* And try to understand every part.

This change is helping me to really **learn programming**, not just copy it.
